# Bash Scripting Practice

## Overview

This repository contains the Bash topics I practiced along with practical automation projects. The goal was to understand Bash fundamentals and apply them to real DevOps tasks such as backups, log analysis, and Docker deployment verification.

---

## Topics Covered

- Variables
- Command Line Arguments
- User Input
- Arithmetic Operations
- Conditional Statements (if-else)
- Loops
- Arrays
- Functions
- File Handling
- Exit Codes
- Command Substitution

---

## Projects

### 1. Backup Automation

Automates the backup process by copying files from a source directory into a timestamped backup folder.

**Features**

- Accepts source directory as an argument
- Validates user input
- Creates timestamped backups
- Copies files automatically

---

### 2. Log Analyzer

Analyzes a log file and displays:

- Total ERROR messages
- Total WARNING messages
- Total INFO messages
- Recent log entries

---

### 3. Docker Deployment Verifier

Verifies whether a Docker deployment is healthy.

**Checks**

- Docker installation
- Docker service status
- Running container
- Application accessibility
